# GITHUB TYPES OF REPOSITORIES

When working with GitHub, there are several ways to manage your code repositories. Below are the main types of repositories you can use, along with their characteristics:

|Acción|¿Dónde vive el código?|¿Se ve en tu perfil?|¿Puedes subir cambios?|
|---|---|---|---|
|Clone directo|Tu PC|No|No (solo local)|
|Fork + Clone|Tu GitHub + Tu PC|Sí|Sí|
|Repo Propio (Manual)|Tu GitHub + Tu PC|Sí|Sí|
